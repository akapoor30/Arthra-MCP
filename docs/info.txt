Project Name: Arthra MCP (Indian Stock & Mutual Fund Financial Analyst)

Overview:
An AI-powered Financial Analyst agent leveraging MCP (Model Context Protocol) to query, compute, analyze, and visualize Indian equity stocks (NSE/BSE via yfinance) and Indian Mutual Funds (AMFI via mfapi.in).

Architecture & Features:
1. Data Engine: Ingestion of real-time & historical quotes for Indian stocks (.NS / .BO) and Mutual Funds scheme NAVs.
2. Analytics Engine: NumPy & Pandas quantitative engine for RSI, MACD, Moving Averages, Beta vs NIFTY 50, Valuation metrics, CAGR, Sharpe Ratio, and Drawdowns.
3. Visualization: Interactive Plotly Candlestick charts, Technical Subplots, Mutual Fund NAV Trajectory curves, and Relative Return comparisons.
4. MCP Server: Standard FastMCP tools for LLM agent integration.
5. Financial Analyst Agent: Automated agent producing structured markdown financial reports with visual chart embeds.
