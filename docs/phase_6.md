# Arthra MCP — Phase 6 Explanation: Financial Analyst Agent & Interactive CLI Interface

This document provides a detailed technical breakdown of **Phase 6** implementation for **Arthra MCP**, covering natural language query orchestration, markdown report generation, and CLI entry points.

---

## 1. Overview & Components Built

In Phase 6, we built the autonomous agent layer that transforms natural language queries into MCP tool calls and synthesizes executive financial analyst reports:
1. `src/agent/agent.py`: `FinancialAnalystAgent` orchestrator managing tool execution (`stock_fetcher`, `mf_fetcher`, `technicals`, `fundamentals`, `mf_analytics`, `chart_builder`) and markdown report generation saved into `reports/`.
2. `main.py`: Command-Line Interface (CLI) entry point offering flags for running the FastMCP server (`--server`) or running interactive agent queries (`--agent`, `--stock`, `--mf`).
3. `demo_client/demo_agent.py`: Demonstration runner executing stock and mutual fund research workflows.
4. `tests/test_agent.py`: Unit test suite verifying agent intent resolution and markdown report generation.

---

## 2. Agent Report Synthesis Engine

When a user or LLM host asks a query (e.g., *"Analyze Reliance Industries"* or *"Analyze Parag Parikh Flexi Cap Fund"*), the Agent:
1. **Intent Resolution**: Identifies if the query targets an Indian Stock or Mutual Fund, and resolves ticker symbols/scheme codes using `tool_search_indian_symbol`.
2. **Tool Execution**: Invokes `tool_analyze_and_visualize` to run quantitative technical indicators, 100-point fundamental scorecard models, or mutual fund CAGR/Sharpe/drawdown analysis.
3. **Plotly Chart Generation**: Automatically generates and saves interactive dark-mode HTML charts into `charts/`.
4. **Structured Markdown Generation**: Formats findings into executive research reports containing ratings, metric breakdown tables, technical signal highlights, and embedded local chart links (`file:///.../charts/<name>.html`).
